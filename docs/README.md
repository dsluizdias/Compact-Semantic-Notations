# Docs index

This folder is structured by scope:

- **Cross-notation** (applies to the whole family of notations):
  - [notations/README.md](notations/README.md) — how each notation works, with worked examples
  - [landscape.md](landscape.md) — positioning of all notations and the selection rule
- **CMN-specific** (the main notation):
  - [cmn/spec.md](cmn/spec.md) — formal spec
  - [cmn/dictionary.md](cmn/dictionary.md) — vocabulary
  - [cmn/examples.md](cmn/examples.md) — examples
  - [cmn/tests.md](cmn/tests.md) — compression and meaning tests

Portuguese versions of each file are alongside with the `.pt-BR.md` suffix.

If you are new here, start with [notations/README.md](notations/README.md), then dive into [cmn/spec.md](cmn/spec.md) for the main notation.
